# Information-Systems-Analysis-and-Design
This project contains a comprehensive analysis and design documentation of an Ecommerce Information System. It includes detailed system requirements, use case diagrams, UML models, database design, and business process analysis.

The system design was developed to support an efficient and scalable Ecommerce platform, focusing on user requirements, software architecture, and system workflows to ensure smooth operation and high usability.

Additionally, the project incorporates UI/UX design prototypes created with Figma, providing wireframes, mockups, and interactive prototypes to enhance the user experience and interface design.

# Key features of this project include:

Detailed system analysis and requirement gathering

UML diagrams (use case, class, sequence diagrams)

Database schema and design

Business process modeling

Software architecture and design patterns

UI/UX wireframes and prototypes using Figma

Responsive and user-centered design approach
